# 0002 Visual direction: "Ledger"

**Status:** accepted · 2026-10-16 · supersedes the draft "Postcards from time off" direction

**Context:** The first draft direction (warm paper, postcard and postmark motifs) and a
Gemini-generated mockup both read as too casual. Away is an internal tool, but it
represents the company and may be handed off for real internal use.

**Options compared:** A · Ledger (navy + teal, IBM Plex Sans) · B · Boardroom
(forest + brass, serif headings) · C · Clarity (graphite + cobalt, Manrope).

**Decision:** Ledger. It reads like trusted HR/finance software, holds up in dense
tables and calendars, has a matching mono face for dates and IDs, and carries over
cleanly to the documentation and presentation.

**Consequences:** Postcard motifs are dropped. The tokens in `docs/design/DIRECTION.md`
are the single source for the app, docs and presentation. Boardroom was the runner-up
(more elegant, but too formal for day-to-day use). Clarity was too close to a generic
SaaS template.
